# Подключение российских нейросетей: GigaChat и YandexGPT

Эта инструкция — для подключения HR-ассистента к **GigaChat** (Сбер) и **YandexGPT** (Яндекс). Оплата в рублях, картой российского банка, данные обрабатываются в России.

**Зачем нужен «сервер-посредник».** Сервисы Сбера и Яндекса не принимают запросы напрямую со страницы в браузере, а для GigaChat ещё нужен сертификат Минцифры. Поэтому между приложением и нейросетями ставится маленькая облачная функция в Яндекс Облаке. Ключи хранятся в ней, а не в браузере. В приложении вводятся только адрес функции и пароль.

Займёт около 40 минут. Названия кнопок могут немного отличаться: сервисы иногда меняют интерфейс. Если что-то выглядит иначе — сделайте скриншот и спросите.

---

## Шаг 1. GigaChat: получить ключ авторизации

1. Откройте [developers.sber.ru](https://developers.sber.ru/) и войдите через **Сбер ID**.
2. Перейдите в раздел **GigaChat API** и создайте проект для **физического лица**.
3. В настройках проекта нажмите **«Получить ключ»** (или «Сгенерировать новый ключ»).
4. Скопируйте **«Ключ авторизации»** (Authorization key) — длинная строка из букв и цифр. Сохраните его в надёжном месте: сервис покажет его один раз.
5. Тип доступа для физлица — `GIGACHAT_API_PERS`. Для физлиц обычно есть бесплатный пакет токенов; дополнительные пакеты покупаются в рублях в том же кабинете.

## Шаг 2. Сертификат Минцифры (нужен для GigaChat)

1. Откройте [gosuslugi.ru/crt](https://www.gosuslugi.ru/crt).
2. Скачайте **корневой сертификат** (файл `.crt` или `.cer`).
3. Откройте скачанный файл в **Блокноте** (правой кнопкой → «Открыть с помощью» → Блокнот):
   - если внутри текст, начинающийся с `-----BEGIN CERTIFICATE-----`, — отлично, он понадобится на шаге 4 (вариант А);
   - если внутри «кракозябры» — используйте вариант Б на шаге 4.

## Шаг 3. Яндекс Облако: ключ для YandexGPT

1. Откройте [console.yandex.cloud](https://console.yandex.cloud/) и войдите через **Яндекс ID**.
2. Создайте **платёжный аккаунт** (физическое лицо, карта российского банка). Новым пользователям обычно дают стартовый грант на пробу — условия смотрите на сайте.
3. На главной странице консоли откройте каталог **default** и скопируйте его **идентификатор** (строка вида `b1g...`). Это `YANDEX_FOLDER_ID`.
4. Слева выберите **«Сервисные аккаунты»** (или «Identity and Access Management» → «Сервисные аккаунты») → **«Создать сервисный аккаунт»**:
   - имя: `hr-assistant`;
   - роли: **`ai.languageModels.user`** (YandexGPT) и **`ai.vision.user`** (распознавание текста на картинках).
5. Откройте созданный аккаунт → **«Создать новый ключ»** → **«Создать API-ключ»**. Скопируйте **секретную часть** ключа — это `YANDEX_API_KEY`. Её тоже покажут один раз.

## Шаг 4. Создать функцию-посредник

1. В консоли Яндекс Облака откройте **Cloud Functions** → **«Создать функцию»**. Имя: `hr-proxy`.
2. Выберите среду выполнения **Node.js** (последняя доступная версия, 18 или новее).
3. Загрузите код — один из вариантов:
   - **А. Через редактор** (если сертификат текстовый):
     - в редакторе откройте файл `index.js`, удалите всё и вставьте содержимое файла [`index.js`](index.js) из этой папки;
     - нажмите **«Создать файл»**, назовите его `russian_trusted_root_ca.pem` и вставьте текст сертификата целиком, включая строки `BEGIN` и `END`.
   - **Б. ZIP-архивом** (если сертификат двоичный): положите в одну папку `index.js` из этой папки и скачанный сертификат, переименовав его в `russian_trusted_root_ca.cer`. Выделите оба файла → «Сжать в ZIP» → в функции выберите способ «ZIP-архив» и загрузите его.
4. **Точка входа:** `index.handler`.
5. **Таймаут:** `300` секунд (длинные документы пишутся до нескольких минут). **Память:** 128 МБ достаточно.
6. **Переменные окружения** — добавьте:

   | Имя | Значение |
   |---|---|
   | `APP_PASSWORD` | придумайте длинный пароль (12+ символов) — его же вы введёте в приложении |
   | `ALLOWED_ORIGIN` | `https://denlehov28-creator.github.io` |
   | `GIGACHAT_AUTH_KEY` | ключ авторизации из шага 1 |
   | `GIGACHAT_SCOPE` | `GIGACHAT_API_PERS` |
   | `YANDEX_API_KEY` | секретная часть API-ключа из шага 3 |
   | `YANDEX_FOLDER_ID` | идентификатор каталога из шага 3 |
   | `FB_KEY`, `FB_SECRET` | ключи Kandinsky с [fusionbrain.ai](https://fusionbrain.ai/) — по желанию, для картинок |

7. Нажмите **«Сохранить изменения»** / **«Создать версию»**.
8. На вкладке **«Обзор»** функции включите **«Публичная функция»** (иначе приложение не сможет к ней обратиться). Защиту обеспечивает пароль `APP_PASSWORD`.
9. Скопируйте **ссылку для вызова** вида `https://functions.yandexcloud.net/d4e...`.

## Шаг 5. Подключить в приложении

1. Откройте [HR-ассистент](https://denlehov28-creator.github.io/HR-/) → **Настройки**.
2. В поле **«Нейросеть»** выберите **GigaChat** или **YandexGPT**.
3. Вставьте **адрес функции** и **пароль приложения** (`APP_PASSWORD`).
4. Нажмите **«Проверить подключение»** — должно появиться «Подключение работает».
5. Переключая GigaChat и YandexGPT, можно сравнить, какой лучше справляется с вашими задачами.

## Расходы и как их контролировать

- **GigaChat:** бесплатный пакет для физлиц, дальше пакеты токенов в рублях.
- **YandexGPT:** оплата за объём текста. Lite-модель заметно дешевле Pro.
- **Cloud Functions:** у Яндекс Облака есть бесплатный объём вызовов в месяц; для одного пользователя его, как правило, хватает.
- В Яндекс Облаке настройте **бюджет с уведомлением**: «Биллинг» → платёжный аккаунт → «Бюджеты» → создать бюджет, например на 500 ₽ в месяц.

## Если не работает

| Сообщение в приложении | Что проверить |
|---|---|
| «Неверный пароль сервера-посредника» | Пароль в «Настройках» совпадает с `APP_PASSWORD` в функции |
| «Нет связи с сервером-посредником» | Ссылка функции скопирована целиком; функция **публичная** |
| «Не найден файл сертификата Минцифры» | Рядом с `index.js` есть `russian_trusted_root_ca.pem` (или `.cer`) |
| «GigaChat (авторизация): …» | Ключ авторизации скопирован без пробелов; `GIGACHAT_SCOPE` = `GIGACHAT_API_PERS` |
| «YandexGPT: … (код 401/403)» | API-ключ и ID каталога; у сервисного аккаунта роль `ai.languageModels.user` |
| «Распознавание текста … (код 403)» | У сервисного аккаунта роль `ai.vision.user` |
| «Сервис не ответил вовремя» | Таймаут функции 300 секунд |

**Безопасность.** Никому не пересылайте ключи и пароль приложения. Если ключ мог утечь — удалите его в кабинете сервиса, создайте новый и обновите переменную окружения функции.
