# Дизайн-система HR-ассистента

Стиль: спокойный деловой интерфейс для HR-специалиста. Светлая и тёмная темы, много воздуха, никаких «игровых» эффектов. Пользователь — не программист, поэтому всё подписано по-русски простыми словами.

Приложение без сборки: `index.html` + `css/app.css` + ES-модули в `js/`. Сторонние библиотеки — только собранные в `vendor/` (`npm run build:vendor`), без CDN в рантайме (исключение — Google Fonts для шрифтов бренда).

Тёмная тема задаётся дважды: `@media (prefers-color-scheme: dark)` с `:root:not([data-theme="light"])` и `:root[data-theme="dark"]`. Новый токен добавляй во все три места. Цвета только через переменные, никаких hex в компонентах.

Радиусы: карточки `--radius` 14px, кнопки и поля 10px, чипы и бейджи — пилюли (999px). Тень: `--shadow` (в тёмной теме нет). Шрифт интерфейса: системный стек `--font`.

## Компоненты и хелперы (переиспользуй, не пиши заново)
- `h(tag, attrs, ...children)` из `js/ui.js` — создание DOM. `false`/`null` в детях пропускаются, но `root.append(false)` выведет «false»: для условных блоков на верхнем уровне используй `cond ? h(...) : ""`.
- `field(label, control, hint)`, `select(name, options, value)`, `formData(form)`.
- `resultPanel({ kind, title, onRefine })` — единая панель ответа ИИ: потоковый вывод, «Остановить», «Копировать», «Скачать Word», «Сохранить», строка «Доработать». Ответы ИИ, где есть подсказки, делятся разделителем `SPLIT` из `js/prompts.js`.
- `toast(msg, "ok"|"error")`, `download(name, blob)`, `copyText`, `md(text)` (Markdown через marked + DOMPurify).
- `emptyKeyNotice()` — плашка «нужен ключ API» в разделах с ИИ.
- CSS-классы: `.card`, `.stack`, `.row`, `.grid-2`/`.grid-3`, `.btn` + `.btn-primary`/`.btn-ghost`/`.btn-danger`/`.btn-lg`, `.notice`/`.notice-strong`, `.warn`, `.ok`, `.tabs`, `.chips`/`.chip`, `.badge`, `.md`.
- Атрибут `hidden` работает везде благодаря `[hidden] { display: none !important; }` — не убирай это правило.

## Новый раздел
1. Модуль `js/<раздел>.js` с `export async function render(root, params)`.
2. Строка в `ROUTES` в `js/main.js` (название, эмодзи-иконка, функция).
3. Шапка: `div.page-head` с `h1` и `p.lead` (одно предложение: что даёт раздел).
4. Плитка на главной (`home` в `js/pages.js`), если раздел самостоятельный.
5. Данные — через `js/store.js` (IndexedDB). `localStorage` — только для мелочей вроде темы, и в try/catch.

## Дизайн-студия: неприкосновенные правила
- **Логотип никогда не перерисовывается и не отправляется в ИИ.** Только `drawImage` оригинального файла с исходными пропорциями. Не добавлять повороты, фильтры, тени, обрезку, перекраску, смену прозрачности логотипа.
- Соблюдать охранное поле (`brand.clearZone`) и минимальный размер (`brand.minLogoPx`); текст и декоративные фигуры не заходят в зону логотипа.
- Цвета макета — только из палитры бренд-кита; цвет текста по умолчанию выбирается по максимальному контрасту.
- Любое нарушение брендбука — предупреждение в `warn-box`, а не молчаливое исправление.
- Новые шаблоны — в `TEMPLATES`, форматы — в `FORMATS` (`js/design.js`).

## Тексты интерфейса
- По-русски, на «вы», коротко, без жаргона и англицизмов (не «промпт сгенерирован», а «Промпт готов»).
- Кнопки — глагол действия: «Составить документ», «Скачать Word».
- Ошибки — что случилось и что делать: «Ключ API не подходит. Проверьте его в разделе «Настройки»».
- Пустые состояния подсказывают следующий шаг.
- Помни о 152-ФЗ: в плейсхолдерах вместо реальных данных — [ФИО], [должность].

## Правила качества
- Mobile-first: проверять на 390×844 и 1400×1000, без горизонтального скролла, поля сбоку от 16px.
- Тап-зоны не меньше 40px, фокус виден (`outline` на `--primary`).
- Контраст текста AA в обеих темах.
- После изменений UI: `python3 -m http.server`, прогнать Playwright, проверить скриншоты глазами в светлой и тёмной темах; ИИ в тестах подменять маршрутом `page.route('https://api.anthropic.com/**')`.
- `node --check` на изменённых файлах из `js/`.
